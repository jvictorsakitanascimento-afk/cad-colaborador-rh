# Sistema de cadastro e bonificação de novos colaboradores

## Descrição

Sistema responsável pelo cadastro de novos colaboradores. No sistema, deverá ser informado o nome do colaborador e seu respectivo salario. O sistema deverá retomar uma mensagem de boas vindas dizendo ao colaborador o seu sálario base juntamente com o seu salário bonificado com 15%
## Funcionalidade
### O sistema possui as seguintes funcionalidades:
Cadastro do nome do funcionário 
Cadastro do cargo do funcionário;
Cadastro do salário;
Cálcuolo automático do bônus de boas vindas;
Exibição dos dados cadastrados e dos valores calculados.
## Como utilizar
### Para utilizar o sistema, o usuário deverá:
Informar o bome do funcionário:
Informar o cargo ocupado pelo funcionário;
Informar o salário mensal;
executar o cálculo;
O sistema calculará automaticamente o Bônus de 15%;
O resultado aparecerá na tela.
